**Rules of this file.** ROADMAP.md is the single source for order and state. STATUS.md only refers to IDs. Order and scope change only with a DECISIONS entry, never silently. Every interim report names the changed rows. Nothing is listed as "done" that is only partially done; partial states get their own rows. Status values: open · in progress · waiting for Jonas · done · deferred · dropped. "D…" in the DECISIONS column means the entries of 2026-10-24 with that short code; otherwise the title of the entry is given.

## 5. Risks and assumptions

| Risk / assumption | Impact | Countermeasure |
|---|---|---|
| surrealkv holds the file lock until the process ends | no reopening within the process | keep the client for the process lifetime; tests via child processes |
| Additive rollouts rule out data migrations | restructurings (remove field, retype) not possible via rollouts | intended (Jonas): data migration is the developers' business, separate script |
| SurrealKit is beta (1.0.0-beta.6), bus factor 1 (one main developer), 12 open issues | behavior changes between betas; stagnation possible | pin the version exactly, tests from D4 as regression net, use only as a crate |
| Laravel version provisional (13.38.0) | R2/R3 measure against the wrong version | pin the reference checkout to the target version |
| surrealkv in SurrealDB 3.3.4 is 0.21.x, not 1.0 | older engine generation as default | watch maintenance; check with the next SDK update (RocksDB/TiKV deliberately not built in) |
